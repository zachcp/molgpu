# Gate 2 audit — 2026-09-20

The closed Phase 2 epic matches the architecture review's accepted shape:
Spacefill and Bonds are separate primitive paths, and BallAndStick composes them
under one Structure with one selection and color field. The built-ins,
annotation joins, and endpoint policy are present.

The initial `test:viewer:gate2` did not exercise a selection. It also swapped
two palettes that both read `element`, so it could not detect the selected
position gather depending on a field's attribute names. Both representations had
that dependency, which could recopy coordinates when a different field required
a different column.

The gather is now split into geometry and style attribute derivation. The
browser probe uses an actual three-atom selection and switches from an element
field to a b-factor field. The image changes; zero new WebGPU storage buffers
are allocated, zero writes target labeled position or segment storage buffers,
and no WebGPU error is reported. Attribute storage and use.gpu internal storage
may be refreshed when the field changes. The node suite and typecheck pass. This
closes the identified Gate 2 proof gap. It does not establish timeline style or
camera updates; those belong to Gate 3.
