# PR #93 Gate 2 retention sampling

CI run `38239554040` on `385988a` failed only `run-gate2.mjs`: the
64-distinct-column probe observed five remaining wrappers against its budget of
at most one. CPU, build, EField, invalidation, retirement and site passed; the
aggregate WebGPU job failed because the viewer group failed.

The original probe passed locally on Chrome 154.0.8037.98 with one remaining
wrapper. The hosted failure is reproduced in the retained CI log, not locally.
Its original sampling waited 200 ms and invoked GC inside the same asynchronous
evaluation that allocated the wrappers. The production cache has a 100 ms reuse
window, but elapsed wall time alone does not establish that its callbacks ran or
that browser collection finished.

The corrected test ends the allocation evaluation before collecting. It awaits
the submitted GPU writes, then invokes exposed GC and samples weak references in
separate browser evaluations. It observes the existing wrapper budget within a
ten-second deadline, crossing a browser task boundary between unsuccessful
samples because `WeakRef.deref()` keeps its target alive for the current task.
The deadline limits test waiting; it is not used as evidence of GPU completion.
The test still requires one shared allocation, sixty-four distinct allocations,
and at most one remaining wrapper. Production cache behavior is unchanged.

Three independent local browser runs passed with zero remaining wrappers, no
geometry writes and unchanged allocation counts. A temporary countercheck that
deliberately held all sixty-four wrappers failed with sixty-four remaining after
the deadline; its source was removed after the run. The corrected test still
detects persistent retention. Its log is
`/private/tmp/molgpu-pr93-gate2-intentional-leak.log`. Formatting and lint
passed. Logs: `/private/tmp/molgpu-pr93-gate2-final-{1,2,3}.log`. Failed hosted
log: `/private/tmp/molgpu-pr93-ci-failed.log`. A fresh hosted run is required to
establish CI acceptance; local repetitions do not establish it.
